# Базовый сервис

Учебный REST API-сервис на Python с использованием **FastAPI**. Проект демонстрирует создание HTTP-эндпоинтов, обработку параметров запросов, возврат данных в формате JSON, загрузку настроек из `.env`, логирование и автоматическое тестирование с помощью `pytest`.

## Возможности

- Проверка доступности и состояния сервиса.
- Получение приветствия с именем пользователя.
- Чтение информации о приложении из переменных окружения.
- Проверка наличия настроек приложения.
- Конвертация температуры из градусов Цельсия в Фаренгейт.
- Генерация случайного пароля заданной длины.
- Генерация случайного целого числа в заданном диапазоне.
- Логирование событий.
- Автоматические тесты для API.

## Технологии

- Python 3.9+
- FastAPI
- Uvicorn
- `python-dotenv`
- `pytest`
- `httpx` — используется клиентом тестирования FastAPI
- `logging` и `secrets` — стандартные библиотеки Python, отдельно устанавливать их не нужно.


## Установка и запуск

### 1. Перейдите в директорию проекта

Откройте в терминале папку, в которой находится `main.py`.

### 2. Создайте виртуальное окружение

```bash
python3 -m venv .venv
```

Активируйте его.

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

В `requirements.txt` должны быть указаны зависимости приложения и тестов, например:

```text
fastapi
uvicorn
python-dotenv
pytest
httpx
```

Установите их:

```bash
python -m pip install -r requirements.txt
```

Если `requirements.txt` уже существует, проверьте, что в нём есть `pytest` и `httpx`, затем выполните команду установки.

### 4. Настройте переменные окружения

Создайте файл `.env` в корневой директории проекта — рядом с `main.py`:

```dotenv
APP_NAME=Базовый сервис
APP_AUTHOR=Ваше имя
```

Укажите нужные значения для имени приложения и автора. Функция `load_dotenv()` загружает переменные из `.env`, а код получает их через `os.getenv()`.

Эндпоинт `/info` возвращает значения настроек или значения по умолчанию, если переменные не заданы. Эндпоинт `/config` сообщает, настроены ли обе переменные.

### 5. Запустите приложение

```bash
uvicorn main:app --reload
```

Сервис будет доступен по адресу: <http://127.0.0.1:8000>

Интерактивная документация API: <http://127.0.0.1:8000/docs>

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## API-эндпоинты

Все перечисленные ниже маршруты используют метод `GET`.

| Путь | Параметры | Описание |
|---|---|---|
| `/` | — | Сообщение о работе сервиса |
| `/health` | — | Проверка состояния сервиса |
| `/hello` | `name` — необязательная строка | Приветствие; по умолчанию имя — `студент` |
| `/info` | — | Имя приложения и автор из настроек |
| `/config` | — | Признаки наличия настроек `APP_NAME` и `APP_AUTHOR` |
| `/convert-to-fahrenheit` | `celsius` — число | Перевод градусов Цельсия в Фаренгейт |
| `/password` | `length` — целое число от 8 до 64, по умолчанию `16` | Генерация случайного пароля |
| `/random` | `minimum` и `maximum` — целые числа, по умолчанию от `-100` до `100` | Генерация случайного целого числа в заданном диапазоне |

### Примеры запросов

#### Главная страница — `GET /`

```bash
curl http://127.0.0.1:8000/
```

Ответ:

```json
{"message":"Сервис работает"}
```

#### Проверка состояния — `GET /health`

```bash
curl http://127.0.0.1:8000/health
```

Ответ:

```json
{"status":"ok"}
```

#### Приветствие — `GET /hello`

```bash
curl "http://127.0.0.1:8000/hello?name=Анна"
```

Ответ:

```json
{"message":"Привет, Анна!"}
```

Если параметр `name` не передан, сервис использует имя `студент`.

#### Информация о приложении — `GET /info`

```bash
curl http://127.0.0.1:8000/info
```

Пример ответа при соответствующих значениях в `.env`:

```json
{
  "app_name": "Базовый сервис",
  "author": "Ваше имя"
}
```

#### Проверка настроек — `GET /config`

```bash
curl http://127.0.0.1:8000/config
```

Пример ответа, если обе переменные заданы:

```json
{
  "app_name_configured": true,
  "app_author_configured": true
}
```

#### Конвертация температуры — `GET /convert-to-fahrenheit`

```bash
curl "http://127.0.0.1:8000/convert-to-fahrenheit?celsius=25"
```

Ответ:

```json
{
  "celsius": 25.0,
  "fahrenheit": 77.0
}
```

Формула: `F = C × 9 / 5 + 32`. Значение Фаренгейта округляется до двух знаков после запятой.

#### Генерация пароля — `GET /password`

```bash
curl "http://127.0.0.1:8000/password?length=20"
```

Ответ содержит длину и сгенерированный пароль:

```json
{
  "length": 20,
  "password": "пример_сгенерированного_пароля"
}
```

Фактический пароль будет случайным. Допустимая длина — от 8 до 64 символов. Если длина не соответствует ограничению, FastAPI вернёт ошибку валидации `422 Unprocessable Entity`.

#### Генерация случайного числа — `GET /random`

```bash
curl "http://127.0.0.1:8000/random?minimum=1&maximum=10"
```

Пример ответа:

```json
{
  "minimum": 1,
  "maximum": 10,
  "number": 7
}
```

Число может отличаться при каждом запросе. Границы диапазона включены. Если `minimum` больше `maximum`, сервис возвращает HTTP `400 Bad Request`.

## Логирование

Для логирования используется стандартный модуль Python `logging`. События уровня `INFO` и выше выводятся в консоль. В журнал записываются вызовы эндпоинтов и основные параметры запросов. Пароль целиком в лог не записывается.

## Автоматические тесты

Тесты находятся в `tests/test_main.py`. Они проверяют ответы эндпоинтов, значения по умолчанию, параметры запросов, работу настроек окружения, допустимую длину пароля и ошибочный диапазон случайных чисел.

Убедитесь, что установлены `pytest` и `httpx`:

```bash
python -m pip install pytest httpx
```

Из корневой папки проекта выполните:

```bash
python -m pytest -v
```

Для запуска тестов без подробного списка:

```bash
python -m pytest
```

Тесты используют `TestClient` FastAPI и не требуют запуска Uvicorn в отдельном терминале. В тестах конфигурации переменные окружения подменяются с помощью `monkeypatch`, поэтому для проверки этих сценариев не нужно менять реальный файл `.env`.

## `.gitignore`

Рекомендуется исключить из Git виртуальное окружение, локальный файл настроек и временные файлы Python:

```gitignore
.env
.venv/
__pycache__/
*.py[cod]
.pytest_cache/
```

Файл `.env.example` можно хранить в репозитории, если в нём приведены только примеры переменных без секретов.
