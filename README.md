# Наш первый сервис

Учебный REST API-сервис на Python с использованием **FastAPI**. Проект демонстрирует создание HTTP-эндпоинтов, возврат данных в формате JSON, работу с переменными окружения и логирование событий.

## Возможности

- Проверка работоспособности сервиса.
- Получение приветственного сообщения с именем пользователя.
- Получение информации о приложении из переменных окружения.
- Логирование событий с использованием стандартного модуля `logging`.

## Технологии

- Python 3.9+
- FastAPI
- Uvicorn
- Logging (стандартная библиотека Python)


## Установка и запуск

### 1. Клонирование проекта

Если проект хранится в Git-репозитории:

```bash
git clone <URL-репозитория>
cd <название-проекта>
```

Если проект уже находится на компьютере, перейдите в его директорию.

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
```

Активация виртуального окружения:

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows:**

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

Создайте файл `requirements.txt` со следующим содержимым:

```text
fastapi
uvicorn
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Модуль `logging` устанавливать отдельно не нужно, так как он входит в стандартную библиотеку Python.

### 4. Настройка переменных окружения

Для эндпоинта `/info` можно задать следующие переменные окружения:

```bash
export APP_NAME="Наш первый сервис"
export APP_AUTHOR="Ваше имя"
```

Команды приведены для macOS и Linux. В Windows PowerShell используйте:

```powershell
$env:APP_NAME = "Наш первый сервис"
$env:APP_AUTHOR = "Ваше имя"
```

Если переменные не заданы, сервис использует значения по умолчанию.

### 5. Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000

Интерактивная документация API:

http://127.0.0.1:8000/docs

## API-эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | Проверка работы сервиса |
| GET | `/health` | Проверка состояния приложения |
| GET | `/hello` | Приветствие пользователя |
| GET | `/info` | Информация о приложении |

### 1. Главная страница

**Запрос:**

```http
GET /
```

**Ответ:**

```json
{
  "message": "Сервис работает"
}
```

### 2. Проверка состояния сервиса

**Запрос:**

```http
GET /health
```

**Ответ:**

```json
{
  "status": "ok"
}
```

### 3. Приветствие пользователя

**Запрос:**

```http
GET /hello?name=Анна
```

Параметр `name` необязательный. Если он не указан, используется значение `студент`.

**Ответ:**

```json
{
  "message": "Привет, Анна!"
}
```

Пример запроса без параметра:

```http
GET /hello
```

**Ответ:**

```json
{
  "message": "Привет, студент!"
}
```

### 4. Информация о приложении

**Запрос:**

```http
GET /info
```

**Ответ при заданных переменных окружения:**

```json
{
  "app_name": "Наш первый сервис",
  "author": "Ваше имя"
}
```

Если переменные окружения не заданы, возвращаются значения `Не указано` и `Не указан`.

## Логирование

Для логирования используется встроенный модуль Python `logging`.

Пример настройки:

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
)

logger = logging.getLogger(__name__)
```

Пример использования:

```python
logger.info("Проверка состояния сервиса")
```

Логи уровня `INFO` и выше выводятся в консоль. Дополнительная установка пакета `logging` не требуется.

## Проверка API

После запуска сервиса можно проверить эндпоинты через браузер, интерактивную документацию `/docs` или команду `curl`.

Например:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый ответ:

```json
{"status":"ok"}
```
